Samay — Watch E-commerce Website

Individual Project • Status: Deployed

Project Overview

Samay is an independently developed watch e-commerce application that demonstrates end-to-end web engineering, database architecture, and cloud deployment on AWS.

Work Performed

  • Designed and implemented the e-commerce layout and catalog browsing functionality.
  • Wrote backend data logic using PHP and integrated MySQL database storage.
  • Configured PayPal payment gateway functionality.
  • Independently launched and provisioned an AWS EC2 instance.
  • Installed, configured, and managed Apache, PHP, and MySQL services on Linux server environment.
  • Configured AWS Security Groups, IAM rules, and deployed the live application independently.

Technologies Used

PHP MySQL AWS EC2 Apache PayPal API
